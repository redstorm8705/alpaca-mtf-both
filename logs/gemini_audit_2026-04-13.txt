*   **HIGH | generate_dashboard.py | `_load_alpaca` & `_load_json` silent failures / default values**
    *   Description: The `_load_alpaca` and `_load_json` functions extensively use `.get(key, default_value)` or `or 0` for critical financial data. While this prevents crashes, it can silently mask real API issues or unexpected `null` responses from Alpaca by substituting `0` (or another default) without a specific, actionable warning. This can lead to a dashboard displaying `0` for metrics like `equity` or `cash` even if the API is failing to provide valid data.
    *   Exact failure condition: An Alpaca API field, e.g., `equity` or `cash`, consistently returns `null` or a non-numeric value, which is then absorbed by `float(acct.get("equity", 0) or 0)` and reported as `0.0` on the dashboard, masking the underlying data problem.

*   **HIGH | main.py / trade_log.json | Incorrect `partial_pnl` Calculation/Recording**
