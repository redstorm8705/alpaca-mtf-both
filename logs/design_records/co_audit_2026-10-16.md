# Connection-optimization (CO) audit — slice 1 (Claude, 2026-10-16)

**Status: PROPOSALS ONLY — every wiring change below needs a Gro/GAI vote.** Each one changes a trading decision, so
each is a design fork or a risk-path change. Nothing here ships from this record.

## Digest (plain English)

The weekly connection audit is owed under the anti-silo mandate, and its cron is still unbuilt. This is the first
slice, run by hand. It covers 80 merged PRs since 2026-10-09 (#566-#666) plus the GEX signal family.

**Top 3 gaps:**

1. **GEX is measured all day but only one tier uses it to decide.**
   - The Day tier uses the dealer-positioning walls for entries and targets.
   - The Swing tier uses GEX for two things only: a stricter score floor on "negative gamma" days, and a size tweak.
   - Swing exits and stops never look at it.
   - Example: a Swing NVDA long sitting just under a big call wall is exactly where the Day tier expects price to
     stall, but the Swing tier keeps the same trailing stop either way.
   - Proposal: let the Swing exit tighten (never loosen) its profit lock when price reaches a call wall. This needs a
     replay first.
2. **The new overnight cap (#654) and the new QHM dip-buy zones (#658) don't know about each other.**
   - When the overnight cap tightens because the book is stressed, QHM can still add on a dip.
   - The QHM 2-slot Swing reserve (#646) already reads the cap, so it is bounded. But the dip zones themselves don't
     get deeper on a stressed day.
   - Proposal: deepen Rung A when K_dyn is below its ceiling (tighten-only). This is risk-path, so it needs the board.
3. **Stale-data awareness stops at a page.**
   - The new freshness alarm (PR #668) pages when the dip zones or the overnight cap go stale. The readers still use
     the stale values silently.
   - Proposal: the dip-add reader skips adds when its zones are more than one completed session old. The overnight-cap
     reader already never loosens, so it needs no change.
   - This is fail-closed, but it changes trade frequency, so it needs the board.

Signals with **no safe cross-use** (recorded once, with the reason) are listed under section C.

## C. No safe cross-use (recorded with the reason)
- **GEX → overnight K:** it would double-count volatility (K already scales with VIX and the book's own worst moves),
  and the cadences don't match.
- **GEX → MRI:** two gates would react to one SPY move. Deferred to the VIX-term-structure item.
- **Day-tier direction rules → Swing:** Swing has its own daily trend filter.
- **Never-loosen profit lock → QHM:** QHM uses a different exit model that already only tightens.
