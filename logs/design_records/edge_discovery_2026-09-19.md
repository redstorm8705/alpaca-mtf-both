## UNANIMOUS FIRST STEP (all 5): ship the TIER-AGNOSTIC PER-TRADE RECORD (measurement foundation)
Additive logging (`trade_logger.log_event(**extra)` is already fsync/never-raise/extensible). Do NOT invent a 3rd log; 3 surgical moves:
1. **Mint a `trade_id` at entry for EVERY tier** (day-tier has it; intraday doesn't — the missing join key).
2. **One record builder** (`make_entry_record`/`make_exit_record` in `trade_logger.py`) so both tiers emit the SAME required fields to `logs/trade_events.jsonl`.
3. **`research/trade_record_reducer.py`** replays trade_events (+ day_tier price_samples for MAE/MFE) → `logs/trade_records.jsonl`, one row per CLOSED trade. Derived ⇒ rebuildable + BACKFILLS existing day-tier data.

**The record (required = `*`):** trade_id*, schema_v*, tier*, symbol*, side*, ts_entry*/ts_exit, **confidence* (calibrated [0,1] — dumb=normalized current score on day 1; the FIELD must exist from trade #1)**, score_raw*/score_max*, **components* {factor:{value,weight,contribution}} (decomposable — the exact ic_engine "Phase 1b" add)**, weights_version*, model_version*, regime* (from `strategy/regime_state.py` — do NOT reinvent), mri_level*/gex_regime*, **indicators* (RAW continuous values: RSI, EMA13/30 spread, MACD hist, VWAP-dev-in-ATR, ATR, TSMOM… — continuous is mandatory for MDA/threshold recalibration)**, entry_price*/stop_price*/target_price*, planned_R*, qty*/notional*; reducer-filled: exit_price, exit_reason, realized_pnl, **realized_R**, **mae_R/mfe_R** (BOTH missing today — add water-mark tracking to the exit path), **outcome_label (triple-barrier +1 target / −1 stop / 0 time — pre-wires LdP meta-labeling)**.

**Enforcing tests (fail if a trade fires without its record):** (a) per-path unit test — mock the logger, drive intraday `record_entry` + day-tier `place_entry` once each, assert every `*` field present/non-null + JSON-serializable (feed a `numpy.bool_` = the D1 regression guard); (b) reconciliation invariant — `count(entries with trade_id) == open+closed trades` AND every exit.trade_id has a matching entry (would have caught the 7-day drop).
